Abstract

The Pennywise Expense Tracker is a web-based application designed to help individuals manage daily expenses, monitor monthly budgets, and analyze spending behavior. The project provides an interactive dashboard for tracking transactions, creating category-wise budgets, and generating monthly budget reports. The system supports efficient data entry, search and filtering features, and downloadable financial summaries in CSV format.

The application was developed using React for the frontend, Express.js for the backend, and MongoDB for persistent data storage. A fallback local JSON storage option was added so the project can run on different machines and in demo environments without requiring a database setup. This makes the system portable for academic demonstrations, team sharing, and deployment in different environments.

The project aims to simplify personal budgeting and improve financial awareness by offering a clear view of spending habits and budget utilization. The system is also scalable and can be extended with additional features such as authentication, recurring expenses, and advanced analytics.

Keywords: Expense Tracker, Budget Management, Web Application, React, MongoDB, Personal Finance

Chapter 1: Introduction
1.1 Background

Personal financial management is an essential part of everyday life. Individuals often struggle to track expenses, manage monthly budgets, and understand where their money is being spent. Most users need a simple and efficient tool that can maintain records of spending and highlight budget exceedances.

The Pennywise Expense Tracker addresses this need by providing a user-friendly interface for recording expenses, tracking budgets, and analyzing financial activity. By presenting data in a clean dashboard layout, the application enables users to make informed spending decisions.

1.2 Identification of Need

Many people use manual notebooks, spreadsheets, or inaccessible applications to track expenses. These methods are often inconvenient and do not provide instant insights into spending patterns. With this project, users can track transactions and categorize them quickly while also assessing how close they are to monthly budget limits.

1.3 Problem Identification
  • Lack of simple digital expense tracking tools
  • Difficulty in identifying spending trends by category
  • Limited awareness of monthly budget usage
  • Poor accessibility for users needing lightweight finance tools
1.4 Task Identification
  • Add and manage expenses
  • Set monthly budgets
  • Filter and search transactions
  • Generate monthly reports
  • Display spending summaries
  • Run in both local and database-backed modes

Chapter 2: Design Flow / Process
2.1 Concept Generation

The application concept was generated around a personal finance dashboard that is easy to understand and use. The primary goal was to create a system that helps users record expenses quickly and view summaries without needing complex financial software.

2.2 Evaluation and Feature Selection

The following features were selected after evaluating the project goals: transaction entry, category-wise spending review, budget management, report generation, search and filter features, and portable deployment support.

2.3 Design Constraints

The project considered several constraints, including ease of use, browser compatibility, data validation, and support for demonstration environments without requiring a database connection. The design also prioritizes maintainability and scalability.

2.4 System Design

The application follows a modular full-stack architecture with a React frontend, Express.js backend, MongoDB database layer, and JSON fallback storage for portability. This approach allows the app to function smoothly in both development and demo deployment settings.

2.5 Design Flow
  1. User enters a new expense or budget.
  2. The frontend sends a request to the backend API.
  3. The server validates the data.
  4. Data is stored in MongoDB or local fallback storage.
  5. The dashboard updates totals and reports.
2.6 Best Design Selection

The selected design was chosen because it balances simplicity, maintainability, and portability. It offers a clean user interface while preserving a scalable backend. The fallback storage feature further improves portability and reduces barriers when sharing the project with teachers and teammates.

Chapter 3: Results Analysis and Validation
3.1 Implementation

The application was implemented using a modular structure. The frontend contains the dashboard, navigation, transaction forms, budget forms, reports, settings, and help pages. The backend contains API handlers for expenses, budgets, and health checks.

3.2 Tools and Technologies Used
  • React.js
  • Vite
  • Express.js
  • MongoDB
  • Node.js
  • JSON fallback storage
3.3 Testing and Validation

The project was validated for expense creation, budget insertion, invalid input handling, filtering, search, report export, and portable execution without MongoDB. The system successfully demonstrates that financial data can be stored and retrieved reliably in both database-backed and local demo modes.

3.4 Result Analysis

The application helps users quickly understand spending patterns across categories. Summary cards provide a snapshot of total monthly expenses, transaction counts, and category breakdowns. The budget section allows users to compare actual spending against planned values, enabling better control of personal finances.

Chapter 4: Conclusion and Future Work

The Pennywise Expense Tracker project demonstrates an effective way to manage personal expenses, analyze spending trends, and monitor monthly budgets through an easy-to-use web application. The project integrates modern web technologies and balances simplicity with practical financial functionality.

The system is not limited to local-only execution. Additional portability support was added to allow the project to run in shared environments and demonstration setups without strict MongoDB configuration. This is especially useful when a project is shared with teachers, teammates, and evaluators.

Appendix A: User Manual

Step 1: Install dependencies

npm install

Step 2: Run the application

npm run dev

Step 3: Open the application

Open the local Vite URL displayed in the terminal, usually http://localhost:5173.

Step 4: Use the app

  • Add expenses from the dashboard
  • Set monthly budgets
  • Filter by date or category
  • Search transaction details
  • Export monthly reports

Step 5: Optional database configuration

If MongoDB is available, create a .env file from .env.example and add the database connection string. If no database is configured, the application automatically uses the local fallback JSON storage file so the project continues to work.
